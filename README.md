## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/T-honrade/Projects.git
```

### Navigate to the JavaScript Folder

```bash
cd Projects/js
```

### Run a JavaScript File

Example:

```bash
node katamaran.js
```

or

```bash
node quiz2.js
```

If the file is inside a folder:

```bash
cd "Algorithm_RealLife_Code(07-23-26)"
node katamaran.js
```
