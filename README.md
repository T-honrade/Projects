- Console-based interface

### 📖 Library Book Borrowing

A Python program that manages book borrowing transactions.

**Features:**
- Display available books

- Return books
- Track borrowed items
- Simple menu-driven interface

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/T-honrade/Projects.git
```

### Switch to the Python Branch

```bash
git checkout py
```

### Run a Project

Example:

```bash
cd ACTIVITY_BrgyVisitorLog
python BrgyVisitorLog.py
```

or

```bash
cd ACTIVITY_LibBookBorrowing
python LibBookBorrowing.py
```

> **Note:** Replace the filenames above if your Python files have different names.
